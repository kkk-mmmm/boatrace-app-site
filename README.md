# BOATRACE NOTE / 公開用

全24場の出走表・固定モデル予想と取得時点オッズを掲載する閲覧専用サイトです。

従来の固定計算式に、開催日・区分別STと展示／本番の差を扱う履歴補正モデルを追加しています。現段階は検証中で、改善が確認できない補正係数は採用しません。生成AI APIは使用しません。桐生の検証成績は他場の成績を意味しません。公式データの取得時刻・更新状態・締切を表示します。

公開承認の初期値はfalseです。一般公開の確認後に公開するコミットを指定し、GitHub PagesのSourceをGitHub Actionsに設定します。

自動更新は日本時間08:00〜21:59に5分間隔を目安とします。GitHub Actionsの実行・反映には遅延があります。

取得した原資料と保存予想はActionsキャッシュへ保管します。キャッシュは永続バックアップではなく、長期の検証資料は別途保存が必要です。
