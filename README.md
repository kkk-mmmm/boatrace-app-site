# BOATRACE NOTE

全24場の出走表・展示情報・固定式予想・取得時点の3連単オッズを表示する閲覧専用サイトです。

公開先： https://kkk-mmmm.github.io/boatrace-app-site/

## 画面で確認できること

- 締切前で新鮮なオッズがあるレースを、期待値（推定確率 × オッズ）の高い順に表示
- 本日開催／非開催、グレード、開催日次、時間帯のタグで全24場を絞り込み
- 出走表と展示情報、選手ごとの過去の展示／本番の差
- 全120通りから選ぶ「推定確率上位」「期待値上位」の各10点と、スコア内訳
- 公式データの取得時刻、締切、未取得・更新待ち・取得失敗の状態

## 予想方式

独自の固定計算式を使い、生成AI APIや外部のAI予想サービスは使用しません。推定確率は計算値であり、実測の的中率ではありません。期待値も計算値で、利益を保証しません。

選手別・コース別・開催日次別・レース区分別のSTと安定度、展示と本番の乖離を集計しています。ただし、576レースを取得した追加検証で履歴補正の改善を確認できなかったため、適用する補正係数は全て0です。画面も「固定式 / 履歴補正は未適用」と表示します。必要得点・必要着順を確認できない勝負掛けは推測しません。

## 更新と運用

自動更新は日本時間08:00〜21:59、5分間隔が目安です。GitHub Actionsの実行・Pages反映には遅延があり、全場が同じ時刻に更新されるとは限りません。ブラウザは配信済みJSONを1分ごとに確認します。10分超の古いオッズ・締切後のレースは期待値順位から除外します。

毎日、日本時間02:10を目安に前日までの結果を照合し、履歴集計を更新します。週次の係数候補は別保存し、自動採用しません。原資料と保存予想はActionsキャッシュ、評価報告は30日のartifactへ保管します。キャッシュ・artifactは永続バックアップではありません。

2026-10-22に所有者から一般公開の承認を取得しました。`.github/publication.json` は確認済みコミットを指定しており、対象コードが変わった場合は配信を停止します。変更後はテストと内容を確認してから確認対象を更新します。

## 開発

Node.js 24、Python 3.12以降の標準ライブラリを使います。外部パッケージのインストールは不要です。

```bash
node --test site/test_data.mjs site/test_update.mjs site/test_approval.mjs
python tools/site/collect_official.py --venue 06 --output site/cache/incoming-06.json
node site/update.mjs site/cache/incoming-06.json
node site/build.mjs --require-current
```

`site/dist/` が配信ファイルです。公式HTML・保存レシート・非公開の学習用データセット・管理用HTTP APIは配信しません。ソース一式の元コミットとファイルハッシュは `RELEASE_MANIFEST.json` に記録しています。

Cloudflareによる5分間隔のオッズ取得と、全120通りからの期待値再計算に対応しました。[本番接続手順](cloudflare/odds/README.md)を参照してください。Cloudflareからの公式オッズ取得を確認し、接続先を設定しています。
