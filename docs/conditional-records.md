# 条件別検証の自動記録

v1.35.0から、`site/conditional-strategies.json` の全22条件を共通の検証対象として保存します。イン50%未満×10/20点の2条件、2〜6号艇の1着確率20%以上×1着固定/含む×10/20点の20条件です。従来の「すべて／イン／それ以外」の絞り込みも別にし、合計66区分を固定します。画面で利用者がどれを選んだかを収集する機能ではなく、閲覧・操作・ログインを必要としません。

最初の本番実行時刻をactivation.jsonへ追記保存し、その時刻以後に保存された固定予想だけを記録します。ルール登録・有効化前の予想を事後の事前検証として取り込みません。初回の有効化時刻は実際のワークフロー実行まで未確定です。

## 保存内容と保持

公開リポジトリの既存 `verification-data` ブランチに以下を保存します。

- `conditional-strategies/conditional-v1/definition.json`: 固定した22条件・確率/オッズの閾値・点数上限・各100円・並び順の版。
- `conditional-strategies/conditional-v1/activation.json`: 実際の自動記録有効化時刻と条件定義のハッシュ。
- `conditional-strategies/conditional-v1/predictions/日付/場/R番号.json`: 締切3分前までの固定提案に対する全66区分の買い目。見送りや入力欠損も区別。保存・オッズ取得・固定・受信時刻、全艇の1着確率、係数版、元の予想ID/ハッシュを保持。
- `snapshots/日付/場/R番号/ID.json`: 既存の保存原本。全120通りの確率と当時オッズ、選手・モデル情報はここへ参照して重複を抑制。条件記録と原本の双方を検証し、結果を見て買い目を再選定しません。
- `conditional-strategies/conditional-v1/reviews/日付.json`: 日別の結果・実払戻・条件ごとの的中と仮想購入額。予想記録から分離した再生成可能な照合レポート。
- `reports/conditional-v1.json`: 条件/傾向/係数版別の見送り・照合待ち・除外・照合済み件数、的中、購入点数・額、払戻、収支、回収率。

条件・予想記録は上書き禁止とし、ハッシュと元予想との照合で改変を検出します。結果の追加や出典の不一致・訂正があれば照合レポートは更新します。古い集計の履歴もGitに残ります。30日経過で条件記録や日別レポートを削除せず、学習側の直近30日窓・公開7日窓とは別に保持します。新しい条件・閾値・順位アルゴリズムを導入するときは定義/実装の新しい版を追加し、conditional-v1の意味を変更しないでください。

## 自動実行と計算

既存の `verification-data.yml` の capture/evaluate/hourly 全モードの後に保存・集計します。captureは従来の予想保存に追随、hourlyは毎時の公式結果照合に追随し、evaluateは公式日次資料で再照合します。GitHub Actionsには実行遅延があります。処理は保存済みJSONだけを読み、新たな公式サイトへのリクエストを追加しません。

固定提案を使うため、画面で締切前の変動中に見えた買い目と、締切3分前基準の最終買い目が異なる場合があります。個人の実購入ではなく、全条件の同じ固定時点を比較する仮想検証です。既存の4艇BOX企画と係数の再学習は変更しません。

- 正常な公式結果・実払戻と保存時の選手を照合できた買い目だけ、1点100円を購入額に算入。回収率は払戻総額÷購入総額で、レース別回収率の単純平均ではありません。
- 条件外/券候補なしはNO_BETとして購入ゼロ。INPUT_INCOMPLETEは別件数。見送りを不的中に数えません。
- 結果待ち、払戻待ちはpending。F/L・欠場・返還・異常・取得元の不一致等は除外。未照合/除外は購入・回収率に入れません。
- 係数版を分け、同じレースで重複する66条件を合算しません。日次プロフィールが変わっても係数が同じなら同じ比較群にします。係数不明はモデルIDごとに分離します。
- Worker固定提案の時刻に依存する記録をWORKER_REPORTED_ONLYと明記し、受信で事前保存を証明できる記録とはみなしません。保存できた固定提案が対象で、全場全レースの網羅は保証しません。

再計算（本番は自動実行）：

```
node tools/prediction/conditional_records.mjs 保存先 site/conditional-strategies.json
node --test tools/prediction/test_conditional_records.mjs
```

今回の範囲は記録と照合基盤です。ユーザー向けの新しい検証結果ページ・任意条件の保存ボタンは追加しません。後から保存済みJSONを使い、各条件の日別成績や場・グレード等の分析を実装できます。
