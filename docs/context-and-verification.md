# 直前条件・評価・検証の拡張

既存のSQLite-backed Durable Objectを利用するため、新しいD1アカウントや秘密情報は不要です。`cloudflare/odds/migrations/002_environment_and_history.sql` 相当の冪等なDDLを初回起動時に実行します。風向コード・風速・波高・予測潮位・地点・取得時刻・出典と、変更しない保存予想・確定結果を保存します。日替わりのdeleteAllは廃止し、内部記録を30日保持します。従来の検証用Gitブランチも引き続き原本を保持します。

## 入力

- 風向は公式水面図の16方向コード。1が上向き、5が右向きの公式図示に合わせて表示し、地理的な方位や向かい風への未検証の変換は行いません。前レース時点の気象が掲載される場合があるため基準ラベルも保存します。波高と潮位は別物です。進入の深さ（スタート位置までの距離）は未取得のため、風だけを根拠に深くなったと推測しません。展示進入と各コースの条件別実績までを扱います。
- 気象庁の近隣地点の予測潮位は潮位表基準面（DL）からのcm値。毎時値の線形補間と1時間差を使います。観測・場内水位・高潮・風の吹き寄せを表しません。地点ごとの共有取得は1日1回、失敗時は5分待って再試行します。大村・若松など適切な参照地点が未設定の場に別の海の値を割り当てません。
- 2コース逃がし率は実進入2コースの選手がいる正常6艇レースのうち、1号艇が実進入1コースから「逃げ」で勝った割合。因果的なアシストや差しの試行率ではありません。自身の差し決着率も別集計し、少数例は全国の同条件へ縮小します。PythonとJSの集計件数・率を照合します。

## モデルと表示

v3/v3.1の計算と保存予想は変更しません。v3.2候補へ逃がし・差し決着・風速条件・風向条件・予測潮位・潮位変化の6特徴量を追加します。風の条件別履歴には結果資料も出典付きで保持しますが、事前入力の時刻が分からない結果時点の風を、そのレースの事前入力として検証に流用しません。直近30日を含む、入手できる年次期間の検証済み保存記録を年次履歴へ照合し、月次係数学習に使用します。SQLは30日、検証用Git原本は30日以上保持し、年次モデルの学習・調整期間にも直前条件が存在するまで蓄積を続けます。365日の選手履歴、日次更新、月次の検証付き採用の方針を維持します。候補の比較結果・入力充足度を保存し、改善未確認の候補を採用しません。

自信度は1着確率の正規化エントロピー・上位差・枠別履歴件数から算出する0〜5の参考指標です。0.5刻みで、欠損分布は未算出、実測的中率として校正した値ではありません。レーダーは6軸のレース内相対順位。白艇は可視性のためグレー、他艇は艇色です。同値は平均順位、欠損はnull。評価・自信度タブ内で艇を選択でき、更新後も選択を保持します。

Chart.js 4.4.8をCDNからバージョン固定・SRI付きで読み込みます。CDN障害でも通常の予想と数値表は表示します。オフライン確認版と静的な運営情報・ガイドはCDNへ依存しません。

## 検証

`GET /v1/verification?date=YYYY-MM-DD&venue=24&offset=0&limit=20`。公開範囲は日本時間の当日を含む7日、limit最大50です。期間外・不正パラメータは400。SQL記録と、検証Gitブランチから出力した改ざん検証済みの7日アーカイブを照合します。内部の30日記録をAPIで取得する機能はありません。ただし公開用Gitリポジトリの既存検証ブランチは公開データであり、非公開保管を意味しません。

確率上位10点と期待値上位最大10点を各100円で購入した仮想的中・払戻・回収率を表示します。未記録・未照合・F/L・欠場・異常着順等は不的中に数えません。払戻は公式の確定払戻だけを使い、保存オッズで埋めません。保存済み記録と選手の一致を確認します。事前受信とWorker時刻による保存は区別します。記録のない過去レースの予想を事後に生成しません。
