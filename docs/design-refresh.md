# v1.46 画面刷新

白い情報面・薄いグレー背景・濃い文字・深いブルーの操作色で、競技データを比較しやすい画面へ変更。外部フォント・画像・UIライブラリは追加しない。艇番色は識別用として保持する。

## 実装範囲

`site/public/style.css` 末尾の race desk ブロックで既存の表示規則を上書き。共通のフォーカス、文字サイズ、罫線、角丸、数字の等幅設定、表のスクロール、操作領域を定義。出走表タブは下線型、買い目順位タブは面の切替型。選択済み買い目は色・行背景・チェックで示す。厳選カードはモバイルでも従来の115px以内を維持。固定操作メニューは既存の1本のみ使用する。

HTML構造・ID・イベント・URL・ラベルは維持。機能、予想計算、各艇の確率、オッズ取得、保存・照合、データ配信経路、追従表示の判定は変更しない。PC・スマホで同じ機能にアクセスできる。英語の装飾見出しはCSSで表示を抑え、日本語の主見出しを優先。
