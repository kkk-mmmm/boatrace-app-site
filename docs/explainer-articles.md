# 期待値と展示STの記事（v1.40.0）

`/expected-value/` と `/exhibition-st/` を独立HTMLとして生成します。ガイド・場別解説・検証との通常リンクを設け、self canonical、WebPage/Article/BreadcrumbList、匿名運営者の著者表示、公開日、サイトマップを追加。記事にJavaScriptや新規の外部通信は不要です。記事公開はGoogleの登録・順位を保証しません。

期待値の記事は推定確率×オッズ、1点と複数点の推定払戻、実回収率の分母、同じ8,000円払戻での10/20点の違いを説明用の計算例として明記します。2%×80倍=1.6倍、1%×50倍=0.5倍。実績を装う数値、予算増加を促す推奨、利益保証は掲載しません。

展示STの記事は既存モデルの `models/exhibition-st/current.json` を読み、選手のn/sum/sum_squaresを合算して平均差・差のRMSE・母標準偏差を計算します。単純な選手平均を平均せず、期間内の照合記録数・選手数・レース数と実際の最初/最後の観測日も示します。対象期間が1年でも全レースを収集したとはみなしません。

展示Fは負のST、本番STは正常な記録に限定した既存集計を使用。本番F/Lは除外。RMSEは本番−展示の差そのものの大きさで、補正モデルの改善率ではありません。平均を今回の展示STへ一律に加算することも推奨しません。モデル係数や原本は変更しません。

人数・対応件数の不整合、二乗和の不整合、範囲外の観測日、当日/未来までの集計、欠損では実数値を未掲載にします。説明用の例を実データ欄へ流用しません。新しいプロフィールが定期更新されるたび、次の公開ビルドで記事の実績値も更新されます。公開日を毎回変更する処理は設けません。

テストでは計算例、既知の加重平均/分散、正常/欠損/未来プロフィール、記事HTML・canonical・Articleスキーマ・相互リンクを確認。ChromiumでJavaScript無効・320px幅の表とリンクも確認します。
