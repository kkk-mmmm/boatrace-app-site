# 展開予想の第一ターン描画 v1.59

## 調査した旧仕様と変更

main c36f9fb時点で、`developmentPaths`は共通4.2秒の旋回終了、主に1本の3次ベジェ、選択艇の固定出口414・他艇466付近、バックの終点を他艇より36以上先へ置く方式だった。買い目の2・3着も内部finishへ割り当てていた。独立したSVG SMILのanimateMotionとstroke-dashoffsetを6秒で同期していた。

今回、予想確率・買い目選定・期待値・モデル・保存処理には変更を加えず、描画を分離した。共通出口・終点による先頭保証を廃止。全艇の旋回出口は同じ基準線x=460、脱出基準はx=300で、到達時刻と速度が違う。表示は選択艇が第1ターンからバックで先行する条件付き例に限定する。レース終盤の勝利・2/3着順・この戦法の発生確率は描画で保証しない。

## ファイルとAPI

- `site/public/development-simulation.mjs`: 決定的な候補生成、幾何、弧長LUT、時間プロファイル、同時刻の占有領域検証。DOM/乱数/外部通信を使用しない。
- `simulateDevelopment(scenario, {maxAttempts})`: 24候補まで探索。全6艇と曲率、マーク、接触、先行条件を検証し、不成立ならvalid:false・boats:[]を返す。
- `boatState(boat,t)` / `fleetState(sim,t)`: 同じ模式時刻から位置・速度ベクトル・進行方向・艇首・段階を返す。`wakePoints`も同じ時刻を使用。
- `site/public/development.mjs`: 旧シナリオの1着確率と最高確率の買い目を維持。進入と戦法の整合、勝利履歴の標本数、過去ST差の時点を確認。SVG・不成立表示・入力説明を生成。
- `site/public/development-player.mjs`: 1つのRAF時計だけを所有。停止、再開、再生し直し、0.5/1倍、シーク、非表示停止、reduced-motionの変更を扱う。
- `site/public/app.mjs`: レース/シナリオのキーでコントローラーを管理。別キー・別DOM・別計画への切替でdisposeし、同じキーのデータ更新は時刻・速度・一時停止を保持。経路入力が変わった場合も再生中の経路は差し替えず、案内を表示し「もう一度再生」で最新経路を採用する。入力更新による途中の横飛びを避ける。再描画でSVGの属性が置換されても同じ状態を即座に描き直す。
- `site/build.mjs` / `site/serve.mjs`: 2つの新しい静的モジュールを配信。

## 時間・曲線・接触

各艇はスリット通過→アプローチ→ターン進入→旋回→脱出加速→バックの6段階を持つ。艇首がスリットに達する時刻を推定STへ揃える。モデル時刻と再生速度を分離し、1倍は模式時間1.5/実時間1、0.5倍はその半分。速度操作で幾何や艇間関係は変わらない。

直線、xが線形のS字ベジェ、2本の四分円近似ベジェを組み合わせる。接続点は同じ位置と単位接線を共有。速度は時間のsmoothstep、その積分を距離とし、弧長LUT（曲線1本100分割）から位置を引く。段階ごとに始終速度が一致する。差しは先行する1コース艇の旋回開始から0.25以上後に切り込み、空間検証を通す。まくりは外側の長い距離を実際に走り、半径に比例して速度を上げない。まくり差しは直進後に外へ攻める曲線、その後に内へ切り込む別曲線を持つ。

艇体は向きを持つ34×14の矩形（表示用艇体を包む保守的な領域）、マークは半径10の円。SATと円/矩形距離で同時刻を検証。最大0.006ごとの検証に加え、区間半分での中心移動と艇首回転の上限分を矩形に加算する。速度上限110へ弧長LUT誤差分1%を上乗せし、角速度上限は速度/最小曲率半径24＋艇首ずれ0.3rad/時刻とする。線形xのベジェは曲率上限6|dy|/dx²、固定四分円近似は1.1/r以下を用い、上限を満たさない候補は拒否する。接触後に位置を押し出す補正はない。

画面の航跡・水しぶき・艇首ずれは同じ状態から算出。航跡は過去1.5模式時間を3段階で薄くし、再生履歴を蓄積しないためシークでも再現する。艇首ずれは最大3度で段階境界で0へ戻る。引き波による減速モデルは実装しない。

## 入力の役割

|入力|描画上の用途|
|---|---|
|平均ST|スリット通過時刻の主入力|
|展示STと過去の展示→本番ST差|前日以前の照合が5件以上あるときだけ25%併用。未来・照合日不明は無視|
|ST順位|上のST情報がない場合だけ代替の模式時刻を作る|
|総合スコア|全艇分ある場合、候補探索の順番にのみ使用。加速力ではない|
|展示タイム|総合スコアが揃わない場合だけ探索順の代替。旋回速度ではない|
|枠別1着率・予想確率|既存の候補選択・情報表示を維持。速度へ重ねて加えない|
|決まり手|正常な勝利時の集計で、全戦術の頻度ではない。20走・対象勝利8件以上で選択艇の戦法参考に使う|
|展示進入|6艇の進入が一意の場合の仮定。本番確定とは表示しない。不明・重複時は全艇枠なり仮定|

少数の戦法履歴は未判定とし、画面に描画用の仮戦法と明記する。他艇は勝利時履歴から戦術を決め打ちせず中立経路。結果データは入力しない。欠場時は6艇の描画を停止する。

## 検証と未対応

`node --test site/test_development.mjs` は旧「4.2秒」「出口座標で先頭」「買い目通りの2/3着」テストを新仕様へ置換。決定性・入力不変・ST時刻・段階時刻・接続・弧長速度・検証サンプルの中間時刻の重複・マーク・差し待ち・まくり差し・再試行と不成立・欠損/欠場/進入変化・舟首ずれを確認。

`node --test --test-concurrency=1 site/test_development_browser.mjs` はChromium CDP（既定127.0.0.1:9222）が必要。停止/再開・速度・シーク・同時刻の航跡再現・自動更新の時刻保持・タブ停止・旧プレイヤーの解放・レース/ケース切替・reduced-motionを確認。`TURN_REVIEW=/tmp/turn-review`で合成ケースの4戦法×PC/390px、61時点と進入/旋回/脱出の画像を記録。実レースの映像や成績ではない。

実映像との比較・パラメータ校正は未実施。流体・引き波の減速、3D、艇ごとの実測加速力・旋回性能、レース終盤の逆転、他艇全てがバックへ出るまでの追従カメラは未対応。占有領域は船体の詳細メッシュではない。有限候補で成立しない場合の表示を設け、全入力で描画できるとは保証しない。
