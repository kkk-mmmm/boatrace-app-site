# リリースノートの更新

履歴の原本は `site/releases.json` です。ビルド時にHTMLへ組み込み、予想やオッズの取得に失敗しても閲覧できます。公開URLは `https://kkk-mmmm.github.io/boatrace-app-site/#releases` です。

利用者向けの機能・画面・予想モデル・取得方法を変更するときは、既存項目をそのまま残し、`releases` 配列の先頭へ新しい版を追加してください。サイト版は `major.minor.patch`、日付は日本時間です。追加機能ではminor、修正ではpatchを進めます。予想モデルのv1〜v3とは独立した番号です。元からサイトの版番号が存在しなかった期間は、公開コミットを根拠に後から整理したことを画面に明記しています。

新しい項目には `version`、`date`、`title`、`changes`（変更点の配列）を指定します。必要なら `notes`（制約・補足）を付けます。既存項目の訂正も新しい版へ追記します。認証情報、内部URL、未公開機能の実装完了を示す記述は含めません。

日々のオッズ・出走表・結果・履歴プロファイルだけの定期更新、テスト・内部資料だけの変更は対象外です。更新方式や学習方式自体を変える場合は追記します。

`node --test site/test_releases.mjs` で形式と追記ルールを検証します。CIは変更前のコミットと比較して、既存履歴の保持と利用者向けコード変更時の新しい項目を確認します。`BASE_SHA=<比較元コミット> node site/check-release-notes.mjs` でも確認できます。公開ワークフローの承認処理でもこのチェックを実行します。
