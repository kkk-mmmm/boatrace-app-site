# 回収率上位タブの条件と導入時の確認

導入条件はオッズ50倍以上・モデルの推定確率1%以上。同率を含めた期待値降順（同率は買い目の辞書順）で10点ずつ表示します。「回収率上位」は実績回収率の順位ではなく、指定条件から抽出した事前候補です。各1点の期待値は推定確率×保存/取得時点オッズ。1%と50倍では0.5倍であり、プラス収支の保証はありません。的中率上位の値もモデルの推定確率です。

実装は画面共通のpredictionRankingを使用し、分析も同じ並び順と最大10点を使います。イン/それ以外の絞り込み、追加10点、買い目選択、締切3分前の保存提案保持を維持します。新タブはオッズが必要で、未取得や保存提案なしの場合は理由を表示します。抽出は丸める前の確率・オッズに対して行います。
