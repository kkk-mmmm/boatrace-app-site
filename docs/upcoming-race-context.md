# v1.49 締切一覧と開催場の次レース表示

- 締切一覧: 既存の全場スケジュールから締切順5件。PCカードは余白を揃え、スマホは2列の短い行にする。
- 場カード: 同じ当日スケジュールの288件以内から、その場の最初の未締切レースを表示。締切済み・別日・無効な時刻は既存upcomingRaceListで除く。未取得・開催終了時に次レースを推測しない。
- 強調: 未締切かつ残り600秒以下の場合だけ。時刻背景と「あと10分以内」を併用。先頭レースだから常に強調する旧ルールは解除。15秒の既存描画周期で更新する。
- ラベル: 全120通りを合算した各艇の1着推定確率。1号艇70%以上はイン優勢、残りで最多45%以上は○号艇に軸、最多35%未満は混戦、それ以外は上位拮抗。丸める前の値で判定。同点時は艇番が小さい方を最多として表示する。的中の保証を含意する鉄板表現は使用しない。

ビルド時にrace_outlooksとして全場の軽量サマリーをdata/current.jsonへ追加。選択中の場は取得済みのcurrentから再計算する。上位10点だけから確率を算出しない。日付・レースキー・締切時刻を照合し、6艇/完全分布/元データの最終成功時刻10分以内（未来時刻許容1分）が確認できる場合に限定。欠場・欠損・古いサマリーは判定待ち。オッズAPI、公式サイトへの追加リクエストや予想係数の変更は行わない。

`site/test_upcoming_context.mjs`で確率境界・締切境界・欠場・不完全分布・異なるレースの混入・古いサマリーを検証する。公開用PRチェックと公開前チェックへ追加。

`site/test_venue_layout_browser.mjs`はCDP接続が必要。合成レースでラベル4種類+未判定、次レース、10分強調、終了済みレース除外、一覧クリックによる戸田2Rへの遷移を確認。1440/1024/768/760/390/320pxで枠内スクロール・横はみ出しを検証する。プレビューの確率や時刻は本番実績ではない。
