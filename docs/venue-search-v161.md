# 場別検索導線 v1.61（変更日 2026-10-31）

場選択カードを固有URLへの通常リンクへ、select・厳選/締切一覧は該当場の固有URLとraceクエリへの移動へ統一。URLを変えずに静的本文が別場になる構造を解消する。共有・戻る・新規タブは通常の文書ナビゲーションを使う。場別URLの場コードを旧venueクエリより優先し、初期HTMLのタイトルをJavaScriptでも維持する。

先行タイトルは桐生・平和島・浜名湖・尼崎・児島だけ。24場共通で生成時点の開催日・締切一覧・現在データへの入口を上に置き、全場選択は当該場詳細の後へ移動。保存版の詳細は折りたたみ、鮮度判定・欠場・古いオッズの抑止は既存処理を再利用する。

トップの小さな解説枠から期待値、展示ST、/venue-lane-one-comparison/へ通常リンク。場別のオッズ・展示・過去傾向から対応記事へ移動でき、記事には24場への帰路がある。

比較記事はannualVenueSummaryとvenueStyleRowsの検証を再利用。同一プロフィール期間の1枠出走数・1着率・全国値を掲載。枠番と実進入、1枠1着と逃げは別定義。欠損・不整合・未来期間は未集計。公開日は2026-10-31に固定。静的検証要約はpublicVerificationArchiveとverificationResponseを再利用し、日付・モデル版・保存証明区分を分離。未照合・欠損を損失へ算入しない。数値が使えないビルドでは方法と動的実績へのリンクを表示する。

予想係数、確率、買い目、取得頻度、保存条件は変更しない。外部ライブラリ・AI APIは追加しない。Chart.jsと旧archiveの遅延取得は維持。
