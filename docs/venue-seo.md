# 場別初期HTML・実績解説と公開取得診断（v1.37.0）

全24場の既存URLを維持し、初期HTMLに公開時点の推定確率上位3点、確率、オッズ、期待値、保存/取得/ページ生成時刻を記載します。サイト内に既存のモデル確率をそのまま使用し、SEO用に再計算しません。鮮度・締切の判定は画面と共通。古い・失敗・参考・締切後のオッズは価格を休止、欠場時は予想を休止。保存版であることと現在の動的表示・公式情報で確認すべきことを明記します。静的HTMLは配信後に時計が進んでも自動では変化しません。最新を保証する表現は用いません。

採用中モデルを既存の検証処理で読み込んだ後、その年次場別プロフィールをHTMLへ渡します。枠別1着率・逃げで1着になった割合・出走数・期間・全国1枠との差を表示。枠番と進入コース、過去実績と今回の確率を区別します。全国との差は観測値の単純な差で、統計的な優位性の判定ではありません。モデル欠損・期限外・当日以後の集計は未集計とし、固定の「大村は強い」等の説明で穴埋めしません。

サイトマップ・robots・canonical・構造化データは既存設定を維持し、場別解説からガイド・検証へ通常のリンクを設置します。公開取得状況は新しい手動Actionsワークフロー「Check public sitemap and crawl delivery」でHTTPS/ステータス/転送先/Content-Type/XML/robotsを確認できます。結果JSONをArtifactへ保存します。GooglebotのUser-Agentを指定する診断は実Googlebotの到達性やSearch Consoleの登録確認を代替しません。

現在の実行環境から公開ホストへの通信はプロキシのTunnel 403で拒否され、Search Consoleへ接続するツールもありません。サイト側が403を返した証拠とはみなさず、実配信・インデックス状態を成功と報告しません。公開ワークフロー実行とSearch ConsoleのURL検査は別途確認が必要です。

確認：node --test site/test_seo.mjs site/test_releases.mjs、python -B site/test_search_delivery.py、既存Chromium画面テスト。新しい本文はJavaScriptを実行しなくてもHTMLに存在します。旧予想・係数・検証記録は変更しません。

## v1.38.0 初期HTMLの閲覧情報と導線

各レースへ出走表（選手・級別・全国勝率・モーター2連率・平均ST）と展示（タイム・ST・進入）を折りたたみで追加しました。未取得を0として補完せず、展示F、進入変化、未提供・失敗・予定・欠場を共通の状態判定で表示します。取得時刻は時・分まで。出走表と展示は予想と異なる時刻の取得になり得るため、各時刻を別記します。

開催・レース一覧、保存予想と展示、場の特徴へ移動する目次を設け、一覧から各レースへジャンプできます。base要素のある場別ページでも正しい場のパスへ移動するよう、URLに場別パスを含めます。最新情報へのリンクと一覧へ戻るリンクも同じ場のページを指します。静的HTMLの鮮度と保存版である旨の扱いはv1.37.0を維持します。

`site/test_venue_browser.mjs` はローカルChromium（CDP 9222）でJavaScriptを無効にして320px幅の出走表・展示・リンクと、折りたたみを開いた時の横はみ出しを検証します。検索登録のための設定・サイトマップ診断は今回変更していません。
